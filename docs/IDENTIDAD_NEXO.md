# Identidad NEXO
Nombre: NEXO. Paleta: naranja #FF783E, grafito #17212B, fondo cálido #F3F1EC, gris #8A98A6.
Texto de acento #B84215 para legibilidad en superficies claras. Texto secundario #5F6C79.
Marca vectorial compartida NexoBrand y nexo-mark.svg. Iconos PWA de 192/512, máscara y Apple con nombres nuevos para evitar iconos anteriores en caché. Se mantiene el id PWA para actualizar la misma instalación.

Navegación pública: Partidos, En vivo, Equipos, Posiciones; el menú complementario permite Calendario y Mis apuestas. El texto técnico, metodología y diagnóstico del aporte de mercado se concentran en Administración. La antigua ruta /metodologia redirige al módulo administrativo autenticado.

La jornada prioriza partidos en vivo y próximos. Ocho encuentros por liga, con expansión explícita, filtros de fecha/estado, y búsqueda. El pronóstico público mantiene probabilidades, totales y estado, con una breve identificación experimental. Las explicaciones completas permanecen en el panel.

Se conservaron cookies, sesiones, usuarios y nombres internos de autenticación para no romper el acceso. El cambio visual no reinicia ni modifica modelos, resultados ni apuestas.
